# タスク詳細: 2.5 本番データ用 .gitignore 設定

## 概要

本番（production）データディレクトリを git 管理外にする。本番データはユーザーごとに異なる実運用データであり、リポジトリにコミットすべきではない。サンプルデータ（`sample/`）は引き続き git 管理下に置く。

## 関連ドキュメント

- PLAN.md: Workspace Phase 2「サンプル・本番データ分離」
- タスク 2.1: document-server データディレクトリ分離（`data/sample/`, `data/production/` 構造の導入）
- タスク 2.2: PostgreSQL データ分離（`postgres/data/sample/`, `postgres/data/production/` 構造の導入）

## 実装計画

### 変更するファイル

| ファイル | 内容 |
|----------|------|
| `.gitignore` | production ディレクトリの除外ルールを追加 |

### 実装手順

1. `.gitignore` に以下のエントリを追加する：
   ```
   # Production data (user-specific, not committed)
   document-server/data/production/
   postgres/data/production/
   ```
2. 既に git 追跡されている `postgres/data/production/.gitkeep` を追跡から除外する：
   ```bash
   git rm --cached postgres/data/production/.gitkeep
   ```
3. production ディレクトリの作成は `scripts/switch-env.sh` が担うため、`.gitkeep` は不要

### 技術的な考慮事項

- `git rm --cached` はワーキングツリーのファイルは削除せず、git インデックスからのみ除外する
- `document-server/data/production/` はまだ存在しないが、先行して .gitignore に登録しておく
- サンプルデータ（`*/sample/`）は除外しない — 動作確認・テスト用として必要
