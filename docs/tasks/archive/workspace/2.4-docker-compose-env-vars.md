# タスク詳細: 2.4 docker-compose 環境変数対応

## 概要

`.env` の `DATA_ENV` 値に応じて、docker-compose 経由で起動した document-server が正しい環境のデータを読み込むことを保証する。`.env.example` に `DATA_ENV` を追加し、全環境変数の設定例を整備する。

タスク 2.1〜2.3 で `DATA_ENV` の仕組み自体は実装済みだが、`.env.example` に `DATA_ENV` が未記載のため、新規セットアップ時に設定漏れが起きる。このタスクで `.env.example` を更新し、docker-compose 経由の動作を検証する。

## 関連ドキュメント

- 要件定義: `docs/requirements/document-server.md` の「前提条件」「環境変数」「受け入れ条件」セクション
  - DATA_ENV で sample/production を切り替え可能（デフォルト: sample）
  - データファイルは環境別ディレクトリ（data/sample/, data/production/）で管理

## 現状分析

タスク 2.1〜2.3 で以下は**実装済み**:

| ファイル | 状態 | 内容 |
|----------|------|------|
| `docker-compose.yml` | 実装済み | `DATA_ENV=${DATA_ENV:-sample}` が document-server と postgres の両方に設定済み |
| `.env` | 実装済み | `DATA_ENV=sample` が定義済み |
| `document-server/src/config.py` | 実装済み | `DATA_ENV` → `DATA_DIR` 解決ロジック、バリデーション済み |
| `.env.example` | **未対応** | `DATA_ENV` が記載されていない |

## 実装計画

### 変更するファイル

| ファイル | 内容 |
|----------|------|
| `.env.example` | `DATA_ENV` 環境変数の追加（説明コメント付き） |

### 実装手順

#### ステップ 1: `.env.example` の更新

`.env.example` に `DATA_ENV` を追加する。既存の変数グループに合わせてセクションを整理する。

```
# Data Environment (sample / production)
DATA_ENV=sample
```

追加位置: ファイルの先頭（他の設定に影響する基本設定のため）。

#### ステップ 2: 動作検証

docker-compose 経由で document-server が `DATA_ENV` の値を正しく受け取ることを確認する。

1. `docker-compose config` で環境変数が正しく展開されることを確認
2. `docker-compose up document-server` で起動し、ヘルスチェックが通ることを確認

### 技術的な考慮事項

- **変更範囲が最小限**: docker-compose.yml と config.py は 2.1〜2.3 で対応済みのため、`.env.example` の更新のみで完了
- **Dockerfile に ENV 命令は不要**: `docker-compose.yml` の `environment:` から注入される設計で、Dockerfile 単体での使用は想定していない
- `.env.example` はテンプレートであり、実際の `.env` には影響しない
