# タスク詳細: 1.1 ワークスペース作成・一覧

## 概要

チャット（AI会話）ごとに独立した作業空間（ワークスペース）を作成・一覧取得するための機能を実装する。ワークスペースはファイルシステム上のサブディレクトリとして永続化され、MCP再起動後も `workspace_list` で再発見できる。

このタスクは Workspace Phase 1（ワークスペース分離）の最初のステップであり、後続の 1.2（既存ツールのスコープ対応）、1.3（結合テスト）の基盤となる。

### 実装手順

#### ステップ1: jupyter-server ワークスペースREST API

`jupyter-server/extensions/custom_api/workspace_handlers.py` を作成し、Tornado ハンドラーを実装する。

**POST /api/workspaces（ワークスペース作成）:**
1. リクエストから `name` を取得（必須、最大100文字）
2. ワークスペースID生成（`ws-{uuid短縮}`）
3. `{WORKSPACE_ROOT_DIR}/{workspace_id}/` ディレクトリを作成
4. `metadata.json`（name, workspace_id, created_at）を保存
5. レスポンスを返却

**GET /api/workspaces（ワークスペース一覧）:**
1. `WORKSPACE_ROOT_DIR` 配下のサブディレクトリを走査
2. 各ディレクトリの `metadata.json` を読み取り
3. ファイル数（metadata.json 除外）をカウント
4. `created_at` 降順でソートして返却
5. metadata.json が存在しないディレクトリはスキップ

**ハンドラー登録:**
`handlers.py` の `get_handlers()` に `/api/workspaces` ルートを追加する。

#### ステップ2: jupyter-mcp 型定義追加

`jupyter-mcp/src/jupyter-client/types.ts` にワークスペース関連の型を追加する。

```typescript
export interface WorkspaceInfo {
  workspace_id: string;
  name: string;
  path: string;
  created_at: string;
  file_count?: number;
}
```

#### ステップ3: jupyter-mcp クライアントメソッド追加

`jupyter-mcp/src/jupyter-client/client.ts` に以下のメソッドを追加する。

- `createWorkspace(name: string): Promise<WorkspaceInfo>` — POST /api/workspaces

### 技術的な考慮事項

#### ワークスペースID生成
- `ws-` プレフィックス + UUID v4 の先頭8文字（例: `ws-a1b2c3d4`）
- ファイルシステムのディレクトリ名としても安全な形式
- 衝突確率は十分に低い（UUID v4の先頭8文字 = 32bit ≈ 40億通り）

#### メタデータの永続化
- `metadata.json` をワークスペースディレクトリ内に配置
- MCP再起動後はディスク上のディレクトリを走査して `metadata.json` を読むことで再発見
- ファイルベースなので外部DBが不要

#### ディレクトリ構造

```
/home/jovyan/work/workspaces/     ← WORKSPACE_ROOT_DIR
├── ws-a1b2c3d4/
│   ├── metadata.json             ← {"workspace_id":"ws-a1b2c3d4","name":"売上分析","created_at":"..."}
│   ├── analysis.ipynb            ← ユーザー・AIが作成するファイル
│   └── ...
├── ws-e5f6g7h8/
│   ├── metadata.json
│   └── ...
```

#### Dockerボリューム
- `./jupyter-server/work:/home/jovyan/work` が既にマウント済み
- ワークスペースはコンテナ再起動後も保持される

#### WORKSPACE_ROOT_DIR の初期化
- ハンドラー初期化時に `WORKSPACE_ROOT_DIR` が存在しなければ自動作成する
- 環境変数 `WORKSPACE_ROOT_DIR` のデフォルト値は `/home/jovyan/work/workspaces`
