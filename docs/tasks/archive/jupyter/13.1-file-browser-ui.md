# タスク詳細: 13.1 ファイルブラウザUI改善実装

## 概要

JupyterLab のファイルブラウザにおけるフォルダ操作を改善する。標準の JupyterLab ではフォルダをシングルクリックするとフォルダ内に移動するが、本タスクではシングルクリックでフォルダの中身をツリー展開（インライン表示）し、ダブルクリックで従来のフォルダ移動を行うように変更する。

`jupyterlab-ai-sync` 拡張に新しいプラグイン `file-browser-customizer` を追加し、`@jupyterlab/filebrowser` の `IFileBrowserFactory` トークンを使用して実現する。

## 関連ドキュメント

- 要件定義: `docs/requirements/jupyterlab-ai-sync.md` の「F5」セクション
- 受け入れ条件: `docs/requirements/jupyterlab-ai-sync.md` の「AC5」セクション

### 要件（F5 抜粋）

- **F5.1**: シングルクリックでフォルダの中身をインライン展開。展開済みフォルダをシングルクリックすると折りたたむ。ツリー展開状態は同一ディレクトリ内で保持し、ディレクトリ変更時にリセット。
- **F5.2**: ダブルクリックでフォルダに移動し中身のみを表示（JupyterLab 標準動作）。

### 受け入れ条件（AC5 抜粋）

- フォルダをシングルクリックすると、そのフォルダの中身がインライン展開される
- 展開済みフォルダをシングルクリックすると、折りたたまれる
- フォルダをダブルクリックすると、そのフォルダに移動し中身のみが表示される
- ディレクトリ変更時にツリー展開状態がリセットされる
- 同一ディレクトリ内でのツリー展開・折りたたみ状態は移動まで保持される
- ファイルブラウザの既存動作（ファイルのシングルクリック選択、ダブルクリック開く）に影響しない

### 実装手順

#### Step 1: package.json に依存関係を追加

`@jupyterlab/filebrowser` を dependencies に追加する。要件定義と CLAUDE.md に `IFileBrowserFactory` の使用が記載されているが、現在の `package.json` には未追加のため追加が必要。

```json
"@jupyterlab/filebrowser": "^4.0.0"
```

#### Step 2: file-browser-customizer.ts を新規作成

`IFileBrowserFactory` トークンからデフォルトのファイルブラウザ (`defaultBrowser`) を取得し、以下のカスタマイズを行う。

1. **DirListing のクリックイベントをフック**:
   - `FileBrowser` ウィジェットの内部 `DirListing` にアクセスする
   - フォルダアイテムのシングルクリック時に、標準の「フォルダに移動」動作を抑制し、代わりにツリー展開/折りたたみを行う
   - ダブルクリック時は標準動作（フォルダに移動）をそのまま実行する
   - ファイルアイテムのクリック動作には一切変更を加えない

2. **ツリー展開状態の管理**:
   - `Map<string, boolean>` でフォルダパスごとの展開状態を管理する
   - セッション中（ページリロードまで）展開状態を保持する

3. **ツリー展開の実装方式**:
   - `ContentsManager` API（`contents.get(path)` ）を使ってフォルダの中身を取得する
   - 展開されたフォルダの中身を DOM 要素として `DirListing` の該当フォルダ行の直下に挿入する
   - 子アイテムにはインデントレベルを付与し、ネスト構造を視覚的に表現する
   - 子フォルダも同様にクリックで再帰的にツリー展開可能にする

4. **クリック判定ロジック**:
   - クリックされた要素がフォルダかファイルかを `DirListing` の `items()` から判定する
   - フォルダの場合: シングルクリック → `event.preventDefault()` + `event.stopPropagation()` でデフォルト動作を抑制し、ツリー展開処理を実行
   - ファイルの場合: 一切介入しない

#### Step 3: プラグインの登録

既存の `jupyterlab-ai-sync:plugin`（AI同期用）とは独立した別プラグインとして定義する。

- プラグインID: `jupyterlab-ai-sync:file-browser`
- `autoStart: true`
- `requires: [IFileBrowserFactory]`（`@jupyterlab/filebrowser` から import）
- `activate` 関数内で `FileBrowserCustomizer` を初期化

`plugin.ts` に複数プラグインを定義し、`index.ts` から配列としてエクスポートする。

```typescript
// index.ts
import aiSyncPlugin from './plugin';
import fileBrowserPlugin from './file-browser-customizer';
export default [aiSyncPlugin, fileBrowserPlugin];
```

#### Step 4: スタイルの追加

`style/index.css` にツリー展開用のスタイルを追加する。

- `.jp-fb-tree-children`: ツリー展開された子アイテムのコンテナ
- `.jp-fb-tree-item`: ツリー内のアイテム行。インデントレベルに応じた `padding-left` を設定
- `.jp-fb-tree-folder-icon` / `.jp-fb-tree-file-icon`: ツリー内のアイコン
- `.jp-fb-tree-expand-icon`: 展開/折りたたみの矢印アイコン（回転アニメーション付き）

#### Step 5: ビルドと動作確認

`scripts/test.sh --rebuild jupyterlab-ai-sync` でリビルドし、Docker 環境で動作確認を行う。

### 技術的な考慮事項

#### IFileBrowserFactory の API

`IFileBrowserFactory` から `defaultBrowser` を取得すると、JupyterLab のメインファイルブラウザの `FileBrowser` インスタンスにアクセスできる。`FileBrowser` は内部に `DirListing` ウィジェットを持ち、ファイル・フォルダ一覧の表示を管理している。

#### DirListing へのアクセス

`FileBrowser` の `DirListing` は直接公開されていない場合がある。以下のアプローチを検討する:
- `FileBrowser` の `node` (DOM) にイベントリスナーを追加し、クリックイベントをキャプチャフェーズで処理する
- クリックされたアイテムがフォルダかどうかは、DOM 要素のクラス名（`jp-DirListing-item` + `data-isdir` 属性等）で判定する

#### シングルクリック vs ダブルクリックの区別

ブラウザのネイティブイベントでは、ダブルクリック時にシングルクリックイベントも先に発火する。これを区別するために:
- シングルクリック時にタイマー（200-300ms）を設定し、その間にダブルクリックが来なければツリー展開を実行する
- ダブルクリックイベントを受けたらタイマーをクリアし、標準のフォルダ移動動作を実行する

#### 既存プラグインとの分離

ファイルブラウザカスタマイズは AI 同期機能とは独立した機能であるため、別プラグインとして実装する。これにより:
- AI 同期プラグインに影響を与えずに開発・テストできる
- 将来的にファイルブラウザカスタマイズだけを無効化することも可能
- `requires` の依存関係が異なる（`INotebookTracker` vs `IFileBrowserFactory`）

#### ContentsManager による子アイテム取得

`FileBrowser` が内部で使っている `ServiceManager.contents` を利用してフォルダの中身を取得する。`contents.get(path)` は `Contents.IModel` を返し、ディレクトリの場合は `content` プロパティにファイル/フォルダ一覧が含まれる。

## テスト計画

### 手動テスト（E2E）

1. **シングルクリックでのツリー展開**:
   - Docker 環境で JupyterLab を起動
   - ファイルブラウザでフォルダをシングルクリック
   - フォルダの中身がインラインで展開されることを確認
   - 再度シングルクリックで折りたたまれることを確認

2. **ダブルクリックでのフォルダ移動**:
   - フォルダをダブルクリック
   - フォルダ内に移動し、パンくずリストが更新されることを確認
   - 戻るボタンで元のディレクトリに戻れることを確認

3. **ファイル操作への非干渉**:
   - ファイルをシングルクリックして選択できることを確認
   - ファイルをダブルクリックして開けることを確認

4. **ネストしたフォルダのツリー展開**:
   - フォルダAを展開 → 子フォルダBをシングルクリック → Bの中身も展開されることを確認

5. **既存機能への非干渉**:
   - AI 同期機能（セル追加・実行同期・ロック）が正常に動作することを確認
