# タスク詳細: 8.9 tests/e2e の prettier 適用

## 概要

tests/e2e/ 配下の TypeScript ファイル（テストファイル + vitest 設定ファイル）に prettier を適用し、コードスタイルを統一する。

## 関連ドキュメント

- 設定: `.prettierrc`
- 類似タスク: `docs/tasks/infrastructure/8.5-prettier-document-mcp-src.md`

## 実装計画

### 対象ファイル

| ファイル | 内容 |
|----------|------|
| `tests/e2e/vitest.config.ts` | vitest 設定ファイル |
| `tests/e2e/e2e-workflow.test.ts` | E2E ワークフローテスト |
| `tests/e2e/sql-analysis-flow.test.ts` | SQL 分析フローテスト |
| `tests/e2e/performance.test.ts` | パフォーマンステスト |

### 実装手順

1. `npx prettier --write tests/e2e/*.ts` を実行（node_modules は除外）
2. `scripts/test.sh tests/e2e` または `npx tsc --noEmit -p tests/e2e/tsconfig.json` で型チェック通過を確認

### 技術的な考慮事項

- `node_modules/` を誤って対象にしないよう `tests/e2e/*.ts` のみに絞って実行すること
- tsconfig.json の `include: ["**/*.ts"]` は `node_modules` を `exclude` しているため型チェックは問題なし
- prettier 適用はスタイル変更のみで動作には影響しない
