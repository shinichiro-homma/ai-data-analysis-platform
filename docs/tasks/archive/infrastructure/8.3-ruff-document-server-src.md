# タスク詳細: 8.3 document-server src の ruff 適用

## 概要

document-server の `src/` ディレクトリ配下の Python ファイル（12ファイル）に ruff フォーマッターおよびリントを適用する。フォーマットのみの変更であり、ロジックの変更は行わない。

### ruff 設定（`document-server/pyproject.toml`）

```toml
[tool.ruff]
target-version = "py311"
line-length = 120

[tool.ruff.lint]
select = ["E", "F", "W", "I", "UP", "B", "SIM"]
ignore = ["E501"]

[tool.ruff.lint.isort]
known-first-party = ["src"]

[tool.ruff.format]
quote-style = "double"
```

### 実装手順

1. ruff format を対象ディレクトリに適用する: `cd document-server && ruff format src/`
2. ruff check で lint エラーを確認・修正する: `ruff check src/`
   - lint エラーがある場合は `ruff check --fix src/` で自動修正を試みる
   - 自動修正できない場合は手動対応するが、ロジック変更にならないよう注意する
3. `scripts/test.sh --rebuild document-server` でテストが通ることを確認する
4. `git diff` で差分がフォーマット変更のみであることを確認する

### 技術的な考慮事項

- フォーマット変更のみであり、ロジック変更がないこと
- ruff の lint ルール（`select = ["E", "F", "W", "I", "UP", "B", "SIM"]`）により、import 順序の整理（I）や Python バージョンアップグレード対応（UP）なども適用される点に注意
- `E501`（行長超過）は ignore されているため、長い行はそのままで問題ない
- `known-first-party = ["src"]` の isort 設定により、`src` パッケージ内のインポートが first-party として分類される
- Docker リビルド + テストが通ること
- `__pycache__/` および `document_server.egg-info/` は ruff の対象外（通常はデフォルトで除外される）
