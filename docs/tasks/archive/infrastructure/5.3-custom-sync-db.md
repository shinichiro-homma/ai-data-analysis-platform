# タスク詳細: 5.3 /custom-sync-db カスタムコマンド

## 概要

`/custom-sync-db` カスタムコマンドの動作確認と、必要に応じた修正を行う。カタログ YAML から DB 初期化スクリプトを再生成し、PostgreSQL を再構築し、スモークテストまでを一括実行するコマンド。

**現状:** コマンド定義ファイル (`.claude/commands/custom-sync-db.md`) と `docs/COMMANDS.md` への記載は既に完了している。残りは動作確認テストのみ。

### 実装手順

#### ステップ 1: カスタムコマンドの動作確認

`/custom-sync-db sample` を実行し、以下の一連フローが正常に動作するか確認する：

1. 環境名の確認（引数 or `.env` の `DATA_ENV`）
2. `scripts/generate-init-scripts.sh sample` — init スクリプト再生成
3. `scripts/switch-env.sh -y sample` — PostgreSQL ボリューム削除 → 再構築
4. `scripts/smoke-test.sh` — スモークテスト

#### ステップ 2: 引数なし時の動作確認

引数なしで `/custom-sync-db` を実行し、`.env` の `DATA_ENV` がフォールバックとして使用されることを確認する。

#### ステップ 3: 問題があれば修正

動作確認で問題が見つかった場合、コマンド定義ファイルを修正する。

### 技術的な考慮事項

- カスタムコマンドは Claude Code が解釈して実行するプロンプトファイルであり、シェルスクリプトではない。Claude Code が各ステップを順番に bash で実行する
- `switch-env.sh -y` の `-y` フラグにより確認プロンプトをスキップしている（Claude Code のbash ツールでは対話入力ができないため必須）
- Docker 環境が起動していることが前提
