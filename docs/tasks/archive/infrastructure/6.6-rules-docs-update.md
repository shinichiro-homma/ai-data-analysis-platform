### 実装手順

#### 1. rebuild-before-test.md の更新

**変更点 A: テスト実行フローの簡略化**

現在:
```
コード変更 → リビルド → テスト実行
```
更新後:
```
コード変更 → scripts/test.sh --rebuild {コンポーネント名}
```
`--rebuild` で MCP/Docker を自動判定するため、手動でリビルドスクリプトを選ぶ必要がなくなった。

**変更点 B: リビルド手順表の簡略化**

現在のリビルド手順表（MCP/Docker/両方の3パターン）に `test.sh --rebuild` を推奨パターンとして追加。手動リビルドは「`--rebuild` が使えない場合」のフォールバックとして残す。

**変更点 C: 例セクションの更新**

`test.sh --rebuild` を使った例を追加:
```bash
# MCP サーバーを変更した場合（自動判定で MCP リビルド）
scripts/test.sh --rebuild jupyter-mcp

# Docker コンテナを変更した場合（自動判定で Docker リビルド）
scripts/test.sh --rebuild document-server

# 統合テストでリビルド付き
scripts/test.sh --integration --rebuild jupyter-mcp
```

**変更点 D: カスタムコマンドでの自動リビルド**

`start-task`, `start-fix`, `refactor`, `complete-task` では `--rebuild` 付きテストが自動実行されるため、手動リビルドは不要であることを記載。

#### 2. freshness-check.md の更新

**変更点 A: チェック対象表の更新**

現在の6項目に加え、Infrastructure Phase 6.5 で追加された項目を反映:

| コンポーネント | 比較対象 |
|---------------|---------|
| document-server (data) | カタログ YAML 更新時刻 vs document-server コンテナ起動時刻 |
| postgres (init) | カタログ YAML vs 生成済み init スクリプト |

**変更点 B: 自動チェック動作表の更新**

`--rebuild` 時の連鎖動作を明記:
- document-server data が STALE → `docker compose restart document-server`
- postgres init が STALE → `generate-init-scripts.sh` + `switch-env.sh` で DB 再構築

**変更点 C: `test.sh --rebuild` のフロー**

`test.sh --rebuild` 使用時:
1. MCP/Docker のリビルドを自動判定・実行
2. Docker 起動中なら `check-freshness.sh` を警告モードで実行

`test.sh --integration --rebuild` 使用時:
1. `DATA_ENV != sample` なら sample に自動切り替え
2. `docker compose up -d --wait`
3. `check-freshness.sh --rebuild` で STALE を自動修正
4. テスト実行

#### 3. scripts.md の更新

**変更点 A: スクリプト一覧表**

`test.sh --rebuild` の説明を更新:
```
scripts/test.sh --rebuild [COMPONENT]  | リビルド + テスト（MCP/Docker 自動判定）
```

**変更点 B: よく使うパターン**

`--rebuild` パターンを追加:
```bash
# リビルド + テスト（推奨: MCP/Docker を自動判定）
scripts/test.sh --rebuild jupyter-mcp
scripts/test.sh --rebuild document-server

# 統合テスト + リビルド（sample 環境に自動切り替え + 鮮度チェック）
scripts/test.sh --integration --rebuild
```

**変更点 C: clean-rebuild.sh の --skip-mcp オプション追加**

```bash
scripts/clean-rebuild.sh --skip-mcp    # MCP ビルドをスキップ（Docker のみ再構築）
```
