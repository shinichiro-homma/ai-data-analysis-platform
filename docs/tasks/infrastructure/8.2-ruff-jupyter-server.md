# タスク詳細: 8.2 jupyter-server の ruff 適用

## 概要

jupyter-server の Python ファイルに ruff フォーマッターを適用する。フォーマットのみの変更であり、ロジックの変更は行わない。

## 関連ドキュメント

- 設定ファイル: `jupyter-server/pyproject.toml` の `[tool.ruff]` セクション

## 実装計画

### 対象ファイル

**extensions/custom_api/ (9ファイル)**
- `jupyter-server/extensions/custom_api/__init__.py`
- `jupyter-server/extensions/custom_api/ai_events.py`
- `jupyter-server/extensions/custom_api/base.py`
- `jupyter-server/extensions/custom_api/handlers.py`

**tests/ (3ファイル)**
- `jupyter-server/tests/__init__.py`

- `jupyter-server/tests/test_sql_handlers.py`

### ruff 設定（`jupyter-server/pyproject.toml`）

```toml
[tool.ruff]
target-version = "py311"
line-length = 120

[tool.ruff.lint]
select = ["E", "F", "W", "I", "UP", "B", "SIM"]
ignore = ["E501"]

[tool.ruff.format]
quote-style = "double"
```

### 実装手順

1. ruff format を対象ファイルに適用する: `cd jupyter-server && ruff format extensions/ jupyter_config/ tests/`
2. ruff check で lint エラーを確認・修正する: `ruff check extensions/ jupyter_config/ tests/`
   - lint エラーがある場合は `ruff check --fix` で自動修正を試みる
   - 自動修正できない場合は手動対応するが、ロジック変更にならないよう注意する
3. `scripts/test.sh --rebuild jupyter-server` でテストが通ることを確認する
4. `git diff` で差分がフォーマット変更のみであることを確認する

### 技術的な考慮事項

- フォーマット変更のみであり、ロジック変更がないこと
- ruff の lint ルール（`select = ["E", "F", "W", "I", "UP", "B", "SIM"]`）により、import 順序の整理（I）や Python バージョンアップグレード対応（UP）なども適用される点に注意
- `E501`（行長超過）は ignore されているため、長い行はそのままで問題ない
- Docker リビルド + テストが通ること
- `.venv/` ディレクトリは ruff の対象外とすること（通常はデフォルトで除外される）
