# タスク詳細: 1.3 Claude Desktop での動作確認

## 概要

Claude Desktop から jupyter-mcp に接続し、実際のデータ分析フローが動作することを確認する。

タスク 1.1（単体テスト）、1.2（MCP Inspector）で個別の動作は検証済み。このタスクでは、最終的なユーザー体験として Claude Desktop を MCP クライアントとして使い、自然言語の指示からデータ分析・可視化・結果確認までの一連のフローが動作することを検証する。

このタスクが必要な理由:
- 1.2 の Inspector テストは手動でツールを 1 つずつ実行する形式であり、AI が自律的にツールを選択・組み合わせるフローは未検証
- Claude Desktop は本番環境で使用する MCP クライアントであり、設定ファイルの正しさやトランスポートの互換性を確認する必要がある
- 画像リソースを含む分析結果を Claude が認識できるかどうかの最終検証

### 実装手順

#### ステップ 1: 環境準備

1. jupyter-server を起動する
   ```bash
   cd jupyter-server && docker-compose up -d
   ```

2. jupyter-mcp をビルドする
   ```bash
   cd jupyter-mcp && npm run build
   ```

3. ビルド成果物を確認する
   ```bash
   ls jupyter-mcp/dist/index.js
   ```

#### ステップ 2: Claude Desktop の MCP 設定

1. Claude Desktop の設定ファイルを編集する

   ファイル: `~/Library/Application Support/Claude/claude_desktop_config.json`

   ```json
   {
     "mcpServers": {
       "jupyter-mcp": {
         "command": "node",
         "args": ["{absolute-path}/jupyter-mcp/dist/index.js"],
         "env": {
           "JUPYTER_SERVER_URL": "http://localhost:8888",
           "JUPYTER_TOKEN": "test-token-123"
         }
       }
     }
   }
   ```

   - `{absolute-path}` はプロジェクトの絶対パスに置き換える
   - 既存の設定がある場合は `mcpServers` に追加する形で記述する

2. Claude Desktop を再起動する
   - アプリケーションを完全に終了（Cmd+Q）してから再起動

3. MCP 接続状態を確認する
   - Claude Desktop のチャット画面でハンマーアイコン（MCP ツール）が表示されることを確認
   - クリックして `jupyter-mcp` の 11 ツールが一覧に表示されることを確認

#### ステップ 3: 基本的な分析フローのテスト

Claude Desktop で以下のプロンプトを送信し、AI がツールを自律的に使用して分析を実行することを確認する。

**テスト 3-1: セッション作成とコード実行**

プロンプト:
```
新しい分析セッションを作成して、Pythonで「Hello from Claude Desktop」と表示してください。
```

確認ポイント:
- Claude が `session_create` を呼び出す
- Claude が `execute_code` で print 文を実行する
- 実行結果「Hello from Claude Desktop」が表示される

**テスト 3-2: データ分析**

プロンプト:
```
pandasでサンプルデータを作成して分析してください。
- 100行のデータ（日付、カテゴリ、金額）
- カテゴリ別の集計
- 基本統計量の確認
```

確認ポイント:
- Claude が `execute_code` でデータ生成コードを実行する
- Claude が `get_variables` や `get_dataframe_info` でデータ構造を確認する
- 分析結果が適切に返される

**テスト 3-3: グラフ描画と画像認識**

プロンプト:
```
先ほどのデータを使って、カテゴリ別の金額を棒グラフで可視化してください。グラフの内容を説明してください。
```

確認ポイント:
- Claude が `execute_code` で matplotlib のグラフ描画コードを実行する
- 実行結果の `images` 配列から `resource_uri` を取得する
- Claude が `get_image_resource` で画像データを取得する
- Claude が画像の内容を認識して説明する（棒グラフの傾向など）

#### ステップ 4: ノートブック操作のテスト

**テスト 4-1: ノートブック作成とセル追加**

プロンプト:
```
「analysis-report」という名前のノートブックを作成して、マークダウンのタイトルセルとコードセルを追加してください。
```

確認ポイント:
- Claude が `notebook_create` でノートブックを作成する
- Claude が `notebook_add_cell` でセルを追加する
- ブラウザで JupyterLab（http://localhost:8888）を開き、ノートブックが存在することを確認

**テスト 4-2: ファイル一覧**

プロンプト:
```
ワークスペース内のファイル一覧を確認してください。
```

確認ポイント:
- Claude が `file_list` を呼び出す
- 先ほど作成したノートブックがリストに含まれる

#### ステップ 5: エラーハンドリングのテスト

**テスト 5-1: エラーコードの実行**

プロンプト:
```
1/0 を計算するPythonコードを実行してください。
```

確認ポイント:
- Claude が `execute_code` でコードを実行する
- ZeroDivisionError が適切に返される
- Claude がエラー内容をユーザーに分かりやすく説明する

#### ステップ 6: セッション管理のテスト

**テスト 6-1: セッション一覧と削除**

プロンプト:
```
現在のセッション一覧を確認して、不要なセッションがあれば削除してください。
```

確認ポイント:
- Claude が `session_list` でセッション一覧を取得する
- Claude が `session_delete` でセッションを削除する
- 再度 `session_list` で削除確認する

#### ステップ 7: 設定手順書の作成

テスト結果を踏まえ、`jupyter-mcp/docs/claude-desktop-setup.md` に以下を記載する:

1. 前提条件
2. 設定ファイルの記述方法
3. Claude Desktop の再起動方法
4. 接続確認方法
5. トラブルシューティング（接続できない場合の対処法）

### 技術的な考慮事項

- **STDIO トランスポート**: jupyter-mcp は `StdioServerTransport` を使用しており、Claude Desktop の標準的な MCP 接続方式（command + args）で直接起動される。追加のプロキシやポート設定は不要
- **環境変数**: `JUPYTER_SERVER_URL` と `JUPYTER_TOKEN` を Claude Desktop の設定ファイルの `env` セクションで渡す必要がある
- **絶対パス**: `args` に指定するパスは絶対パスである必要がある（Claude Desktop が任意のディレクトリから起動するため）
- **既存設定との共存**: ユーザーが他の MCP サーバーを設定済みの場合、`mcpServers` オブジェクトに追記する形で対応する
- **画像リソースの認識**: Claude Desktop が MCP リソース（`resources/read`）を使えるか、または `get_image_resource` ツール経由で画像を取得するかは、Claude Desktop のバージョンに依存する可能性がある。両方のパスで確認する
- **Playwright MCP は使わない**: Claude Desktop の操作はユーザー自身が行う手動テストとなる。Playwright MCP で Claude Desktop を自動操作することはできない
