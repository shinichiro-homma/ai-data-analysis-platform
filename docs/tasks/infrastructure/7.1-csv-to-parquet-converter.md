# タスク詳細: 7.1 CSV → Parquet 変換スクリプト

## 概要

`scripts/convert-csv-to-parquet.py` を新規作成し、`postgres/data/csv/{env}/` に配置された CSV ファイルを Parquet 形式に変換して `postgres/data/{env}/` に書き出す。

CSV の `csv/` ディレクトリへの移動はスクリプトでは行わず、手動（cp コマンド等）で実施する。

Infrastructure Phase 7 全体の目的は、ストレージ効率の改善（CSV 61GB → Parquet 推定 5-10GB）。本タスクはその第一歩として変換スクリプトを提供する。

### 実装手順

1. **`scripts/convert-csv-to-parquet.py` を作成**

   ```
   Usage: scripts/convert-csv-to-parquet.py [--force] <ENV>
   ```

   前提: CSV は事前に `postgres/data/csv/{env}/` に手動配置済みであること。

   処理フロー:
   1. `postgres/data/csv/{env}/` 内の `*.csv` を列挙
   2. 各 CSV に対して:
      - 同名の `.parquet` が既に `postgres/data/{env}/` に存在する場合はスキップ（`--force` で再変換）
      - pyarrow で CSV を読み込み、Parquet（snappy 圧縮）に変換
      - `postgres/data/{env}/{name}.parquet` に書き出し
   3. 変換結果のサマリー（ファイル数、サイズ比較）を表示

2. **`postgres/data/csv/sample/.gitkeep` を作成**

3. **sample 環境の CSV を手動で移動**
   ```bash
   mv postgres/data/sample/*.csv postgres/data/csv/sample/
   ```

4. **sample 環境の CSV を変換してテスト実行**

### 技術的な考慮事項

- **pyarrow の使用**: CSV 読み込みに `pyarrow.csv.read_csv()`、Parquet 書き出しに `pyarrow.parquet.write_table()` を使用。pandas は不要（pyarrow 単体で完結）
- **圧縮形式**: snappy（デフォルト）。PostgreSQL ロード時のデコード速度を優先
- **エンコーディング**: CSV は UTF-8（BOM 付き `utf-8-sig` も考慮）。`generate_init.py` の `read_csv_headers()` が `utf-8-sig` を使用しているため同様に対応
- **CSV の配置**: CSV は `postgres/data/csv/{env}/` に手動で配置する前提。スクリプトは CSV の移動を行わない
- **大ファイル対応**: pyarrow の CSV reader はストリーミング読み込みをサポート。メモリ効率が良い
- **`.gitignore` の確認**: `postgres/data/production/` は既に `.gitignore` に含まれている。`postgres/data/csv/production/` も `.gitignore` に追加が必要
- **`--force` フラグ**: 既存 Parquet を再変換。CSV が `csv/` に移動済みの場合は、`csv/{env}/` から読み込む

### CSV の所在と読み込み元

- **読み込み元は常に `postgres/data/csv/{env}/`**
- CSV が見つからない場合はエラー（`postgres/data/{env}/` にある CSV は自動では読み込まない）
- `--force` 時も `csv/{env}/` から読み込んで Parquet を再生成

### エラーハンドリング

- pyarrow がインストールされていない場合: エラーメッセージ + インストール手順を表示
- CSV ファイルが見つからない場合: 警告を出してスキップ
- 変換に失敗した場合: エラーを出力してそのファイルをスキップ（他のファイルは続行）

   ```python
   print(table.num_rows)
   ```
   - 元 CSV と行数・カラム数が一致すること
