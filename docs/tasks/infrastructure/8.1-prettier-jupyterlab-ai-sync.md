# タスク詳細: 8.1 jupyterlab-ai-sync の prettier 適用

## 概要

jupyterlab-ai-sync の src/ ディレクトリにある TypeScript ファイルに prettier を適用する。フォーマットのみの変更であり、ロジックの変更は行わない。

## 関連ドキュメント

- 設定ファイル: `.prettierrc`

## 実装計画

### 対象ファイル

- `jupyterlab-ai-sync/src/index.ts`
- `jupyterlab-ai-sync/src/plugin.ts`
- `jupyterlab-ai-sync/src/path-utils.ts`
- `jupyterlab-ai-sync/src/websocket-client.ts`
- `jupyterlab-ai-sync/src/notebook-finder.ts`
- `jupyterlab-ai-sync/src/lock-manager.ts`
- `jupyterlab-ai-sync/src/notebook-updater.ts`
- `jupyterlab-ai-sync/src/ui/lock-indicator.ts`

合計: 8ファイル

### prettier 設定（`.prettierrc`）

```json
{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 120,
  "tabWidth": 2
}
```

### 実装手順

1. prettier を src/ 配下の全ファイルに適用する: `npx prettier --write jupyterlab-ai-sync/src/`
2. TypeScript ビルド（`tsc`）が通ることを確認する
3. 差分が純粋にフォーマット変更のみであることを確認する

### 技術的な考慮事項

- フォーマット変更のみであり、ロジック変更がないこと
- TypeScript のビルドが通ること（`tsconfig.json` の `outDir: lib`, `rootDir: src` に注意）
- `package.json` に prettier の devDependencies がないため、プロジェクトルートの `npx prettier` を使用する
