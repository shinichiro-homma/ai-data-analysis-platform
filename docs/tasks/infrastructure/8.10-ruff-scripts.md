# タスク詳細: 8.10 scripts/ の ruff 適用

## 概要

`scripts/` ディレクトリの Python ファイル 2 件に ruff フォーマッターを適用する。フォーマットのみの変更であり、ロジックの変更は行わない。`scripts/` には専用の `pyproject.toml` がないため、`jupyter-server/pyproject.toml` と同等の ruff 設定を `scripts/pyproject.toml` として作成してから適用する。

## 関連ドキュメント

- 参考設定: `jupyter-server/pyproject.toml` の `[tool.ruff]` セクション

## 実装計画

### 対象ファイル

| ファイル | 内容 |
|----------|------|
| `scripts/convert-csv-to-parquet.py` | CSV→Parquet 変換スクリプト |
| `scripts/lib/generate_init.py` | カタログ YAML から DB 初期化スクリプトを生成するライブラリ |

### 実装手順

1. `scripts/pyproject.toml` を作成し、`jupyter-server/pyproject.toml` と同等の ruff 設定（`target-version = "py311"`、`line-length = 120`、`select = ["E", "F", "W", "I", "UP", "B", "SIM"]`、`ignore = ["E501"]`）を記述する
2. ruff format を対象ファイルに適用する: `cd scripts && ruff format convert-csv-to-parquet.py lib/generate_init.py`
3. ruff check で lint エラーを確認・修正する: `ruff check convert-csv-to-parquet.py lib/generate_init.py`
   - lint エラーがある場合は `ruff check --fix` で自動修正を試みる
   - 自動修正できない場合は手動対応するが、ロジック変更にならないよう注意する
4. `git diff` で差分がフォーマット変更のみであることを確認する
5. 動作確認: `scripts/convert-csv-to-parquet.py --help` が正常終了することを確認する

### 技術的な考慮事項

- `scripts/` ディレクトリにはプロジェクトルートの `pyproject.toml` が存在しないため、ruff 設定ファイルを新規作成する必要がある
- フォーマット変更のみであり、ロジック変更がないこと
- ruff の lint ルール（`select = ["E", "F", "W", "I", "UP", "B", "SIM"]`）により、import 順序の整理（I）や Python バージョンアップグレード対応（UP）なども適用される点に注意
- `E501`（行長超過）は ignore されているため、長い行はそのままで問題ない
- スクリプトは `#!/usr/bin/env python3` の shebang 付きであり、実行権限やシェルからの呼び出しには影響しない
