```sql
SELECT
  t.customer_id,
  c.customer_name,
  t.transaction_date,
  t.amount,
  t.status
FROM id_pos_transactions t
JOIN customer_master c ON t.customer_id = c.member_id
WHERE t.status = 'completed'
ORDER BY t.amount DESC
LIMIT 50
```

**操作 6b: 既存ロジックを参考にした集計（Phase 3 のコードを活用）**

```python
# 顧客別の購買集計
customer_summary = df.groupby(['customer_id', 'customer_name']).agg(
    total_amount=('amount', 'sum'),
    transaction_count=('amount', 'count'),
    avg_amount=('amount', 'mean')
).reset_index().sort_values('total_amount', ascending=False)
print(customer_summary.head(10))
```

**操作 6c: グラフ生成**

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = 'DejaVu Sans'

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 左: 顧客別購買金額 Top10
top10 = customer_summary.head(10)
axes[0].barh(top10['customer_id'], top10['total_amount'])
axes[0].set_title('Top 10 Customers by Total Amount')
axes[0].set_xlabel('Total Amount')

# 右: 月別購買推移
df['month'] = pd.to_datetime(df['transaction_date']).dt.to_period('M').astype(str)
monthly = df.groupby('month')['amount'].sum()
axes[1].plot(monthly.index, monthly.values, marker='o')
axes[1].set_title('Monthly Sales Trend')
axes[1].tick_params(axis='x', rotation=45)

plt.tight_layout()
plt.savefig('output/analysis_result.png', dpi=100, bbox_inches='tight')
plt.show()
```
