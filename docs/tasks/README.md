# タスク詳細ファイル

各タスクの詳細な開発計画を格納する。カテゴリ別サブディレクトリ（`jupyter/`, `document/`, `workspace/`, `infrastructure/`）に分割。

- テンプレート: `_template.md`
- 命名規則・作成手順: `.claude/skills/task-plan-creation/SKILL.md` を参照

**完了したタスクの詳細計画は `archive/{カテゴリ}/` へ移動する**（`docs/plan/README.md` のアーカイブ規約を参照）。カテゴリディレクトリは新しいタスクの計画作成時に必要に応じて作成する。
