# タスク詳細: 1.1.7 matplotlib 日本語フォント自動設定

## 概要

matplotlib で日本語ラベルを含むグラフを描画する際、毎回 `import japanize_matplotlib` を明示的に記述しなくても日本語が正しく表示されるようにする。

Jupyter の kernel spec に `exec_lines` を追加し、カーネル起動時に `japanize_matplotlib` を自動インポートする。

`japanize-matplotlib` パッケージは `requirements.txt` に既にインストール済み。

- 要件定義: `docs/requirements/jupyter-server.md`
  - 技術仕様 > プリインストールライブラリ（japanize-matplotlib の記載）

## 実装計画

### 変更するファイル

| ファイル | 内容 |
|----------|------|
| `jupyter-server/Dockerfile` | kernel spec に exec_lines を追加する RUN 命令を追加（既存ファイル編集） |

### 実装手順

1. `jupyter-server/Dockerfile` に RUN 命令を追加
   - Python の kernel spec (`/opt/conda/share/jupyter/kernels/python3/kernel.json`) の `argv` に `--InteractiveShellApp.exec_lines=["import japanize_matplotlib"]` を追加
   - カーネル起動時に自動的に japanize_matplotlib がインポートされる
2. Docker イメージをリビルドして動作確認

### 技術的な考慮事項

- kernel spec の `exec_lines` は IPython カーネル起動時に自動実行されるコード行を指定する仕組み
- `japanize-matplotlib` は matplotlib のフォント設定を日本語対応に変更するライブラリで、import するだけで有効化される
- パッケージは既に `requirements.txt` に `japanize-matplotlib==1.1.3` として含まれているため、追加インストールは不要
