## Phase 24: jupyterlab-ai-sync UI 堅牢化

`tmp/refactor-notes.md` §2 で指摘された jupyterlab-ai-sync のテスト不在とハック（CommandRegistry モンキーパッチ・非公開 DOM 依存）を解消する。不変条件 I4（境界でランタイム検証）の既知違反の解消を含む。実施順は 24.1 → 24.2 → 24.3 → 24.4 → 24.5（24.1 のテスト基盤が後続の回帰防止の前提。24.2〜24.5 は同じ lock-manager / notebook-updater を触るため直列で進める）。各タスクの詳細計画は着手時に `/custom-plan-task` で個別に作成する。監査レポート（`tmp/audit-21.2-21.3-report.md`）の指摘 5・7 は 24.5 で対応する。

| # | タスク | ステータス | E2Eテスト | 備考 |
