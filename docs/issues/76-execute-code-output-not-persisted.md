## 症状

`execute_code` ツールでセルを実行した際、WebSocket 接続クライアントが 1 以上存在するがそのクライアントが対象ノートブックを開いていない場合、実行結果（stdout / 画像 / エラー出力）がどこにも保存されない。

- MCP 側（`execute-code.ts:131`）: `lastBroadcastClientCount > 0` なのでディスク永続化をスキップ
- ブラウザ側（`notebook-updater.ts:443-461`）: 対象ノートブックが開かれていないため `getNotebookAndModel()` が null を返し、セル出力の反映をスキップ

## 再現手順

1. JupyterLab で任意のノートブック A を開く（WebSocket 接続が確立される）
2. MCP 経由で別のノートブック B に対して `execute_code` を呼ぶ（B はブラウザで開いていない）
3. ノートブック B をブラウザで開く → セル出力が空のまま

## 期待する動作

ブラウザ側でセル出力が実際に書き込まれなかった場合、MCP 側がフォールバックとしてディスクに永続化する。
