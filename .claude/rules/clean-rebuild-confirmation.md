# clean-rebuild 実行前の確認ルール

`scripts/clean-rebuild.sh` を実行する前に、**必ずユーザーに明示的な承認を求めること**。失われる情報を説明せずに承認を求めたり、無断で実行することは禁止する。

## 確認時に伝える内容

- **目的**: なぜ clean-rebuild が必要か（環境の不整合修正、初期状態への復元等）
- **失われる情報**: `jupyter_work` ボリューム（ノートブック等）、`postgres_data_*` ボリューム（DB データ）、ビルド済み Docker イメージとキャッシュ
- **`--keep-volumes` の提案**: ワークスペースや DB データを保持したままリビルドできる選択肢があること
