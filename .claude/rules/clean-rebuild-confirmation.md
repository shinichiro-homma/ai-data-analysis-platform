# clean-rebuild 実行前の確認ルール

`scripts/clean-rebuild.sh` を実行する前に、**必ずユーザーに確認を求めること**。

## 確認時に伝える内容

1. **実行の目的**: なぜ clean-rebuild が必要なのか（例: 環境の不整合修正、初期状態への復元など）
2. **失われる情報**:
   - `jupyter_work` ボリューム内の全データ（JupyterLab のノートブック、作成したファイル等）
   - `postgres_data_*` ボリューム内の DB データ
   - ビルド済み Docker イメージとキャッシュ
3. **`--keep-volumes` の提案**: ワークスペースや DB データを保持したままリビルドできる選択肢があることを伝える

## 禁止事項

- ユーザーの明示的な承認なしに `clean-rebuild.sh` を実行すること
- 失われる情報を説明せずに実行の承認を求めること
