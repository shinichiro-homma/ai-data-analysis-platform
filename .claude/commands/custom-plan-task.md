タスク「$ARGUMENTS」の開発計画を作成します。

以下の手順で作業してください：

## 0. ブランチの確認・作成

`.claude/rules/branch-workflow.md` の「ブランチ確認」に従い、現在のブランチを確認してください。

新しいブランチを作成する場合は「ブランチ作成」に従い、ブランチ名は「ブランチ命名規則」の「単一タスク」に従ってください。
既に対象タスクの feature ブランチが存在する場合は、「ブランチ切り替え」に従って切り替えてください。

## 1. タスクの特定（メインで直接実行）

`.claude/skills/task-plan-creation/SKILL.md` のセクション1「タスクの特定」に従い、
`docs/plan/README.md` を Read ツールで読み、対象カテゴリファイルを特定してから該当カテゴリファイルも Read し、タスク $ARGUMENTS を見つけてください。
**サブエージェントは使わず、メインで直接読むこと。**

## 2. 並列調査（必要なサブエージェントのみ起動）

`.claude/skills/task-plan-creation/SKILL.md` のセクション2「調査手順」に従い、
`.claude/skills/parallel-investigation/SKILL.md` のテンプレートを確認した上で、
必要なサブエージェントを並列に起動してください。

## 3. タスク詳細ファイルの作成

`.claude/skills/task-plan-creation/SKILL.md` のセクション3「計画ファイルテンプレート」に従い、
計画ファイルを作成してください。

## 4. レビュー依頼

`.claude/skills/task-plan-creation/SKILL.md` のセクション4「計画作成の報告形式」で報告してください。

## 5. 承認確認

報告後、**必ず `AskUserQuestion` ツールを使って**以下の選択式で確認を取ってください：

**質問:** "この開発計画を承認しますか？"
**選択肢:**
1. **OK** - この計画で進める（`/custom-start-task $ARGUMENTS` で実装開始可能）
2. **Modify** - 修正が必要（修正内容を入力）

### OK が選択された場合

タスク詳細ファイルのレビューステータスを更新してください：

`- [ ] 計画レビュー完了` を `- [x] 計画レビュー完了` に変更します。

### Modify が選択された場合

1. ユーザーが入力した修正内容を確認する
2. タスク詳細ファイルに修正を反映する
3. 修正後の計画を再度報告し、再び承認確認を行う

**注意:** 計画の承認（OK）を得るまで、実装は開始しないでください。
