ドキュメントとコードの整合性を監査します。対象: $ARGUMENTS

以下の手順で作業してください：

## 1. スキルの読み込み

`.claude/skills/doc-code-audit/SKILL.md` を読み込んでください。

## 2. 対象コンポーネントの特定

引数が指定されている場合はそのコンポーネントのみを対象とする。
引数が空の場合はスキルに記載の全コンポーネントを対象とする。

## 3. コンポーネントごとに並列でサブエージェントを起動

スキルの「監査プロンプトテンプレート」を使用し、`{出力形式}` に **Markdown 形式** を埋め込んでください。
サブエージェント設定もスキルに従うこと。

**すべてのサブエージェントを 1 つのメッセージで同時に起動すること。**

## 4. 監査レポートの統合

全サブエージェントの結果を統合し、以下の形式で報告してください。

### 問題なしの場合

```
## ドキュメント監査結果

全コンポーネントでドキュメントとコードが整合しています。

### {コンポーネント名1}: 整合
### {コンポーネント名2}: 整合
...
```

### 問題ありの場合

```
## ドキュメント監査結果

### {コンポーネント名1}: 問題あり

#### A. 欠落 ({N}件)
1. {具体的な内容}

#### B. 陳腐化 ({N}件)
1. {具体的な内容}

#### C. 冗長 ({N}件)
1. {具体的な内容}

### {コンポーネント名2}: 整合

---

`.claude/skills/doc-code-audit/SKILL.md` の「不整合検出時の修正案内テンプレート」を参照してください。
```
