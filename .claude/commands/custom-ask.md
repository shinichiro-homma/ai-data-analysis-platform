ユーザーの質問「$ARGUMENTS」に対して、プロジェクトのドキュメントを調査し回答します。

以下の手順で作業してください：

## 1. 質問の分類

ユーザーの質問を以下のカテゴリに分類してください：

| カテゴリ | 内容 | 主な参照先 |
|----------|------|-----------|
| アーキテクチャ | コンポーネント構成、データフロー、技術スタック | `docs/overview.md`, `CLAUDE.md` |
| 要件・仕様 | 機能要件、MCP ツール仕様、API 仕様 | `docs/requirements/*.md`, `docs/design/api-contracts.md` |
| 開発フロー | コマンドの使い方、ルール、ワークフロー | `docs/COMMANDS.md`, `docs/RULES.md`, `.claude/rules/*.md` |
| 進捗・タスク | タスク状況、計画、次にやること | `docs/plan/README.md`, `docs/plan/*.md`, `docs/tasks/**/*.md`（過去の完了経緯を問われた場合のみ `docs/plan/archive/*.md` / `docs/tasks/archive/**/*.md`） |
| 実装詳細 | コードの構造、具体的な実装方法 | `*/CLAUDE.md`, ソースコード |

複数カテゴリにまたがる場合は、すべてのカテゴリを対象とする。

## 2. ドキュメント調査

分類に基づいて、サブエージェントで関連ドキュメントを調査してください。

**サブエージェント設定:**

- **subagent_type**: `requirements-researcher`
- **model**: `haiku`

**プロンプト:**

```
以下の質問に回答するため、プロジェクトのドキュメントを調査してください。

質問: 「{ユーザーの質問}」

調査対象ファイル:
{分類に基づいて選定したファイルパスのリスト}

調査方法:
1. 上記の各ファイルを Read ツールで読み込む
2. 質問に関連する箇所を抽出する
3. 必要に応じて Grep/Glob で追加情報を検索する（特に実装詳細の質問の場合はソースコードも調査する）

出力形式:
- 関連する記述があったファイルパスと該当箇所（引用）
- ファイル間で矛盾がある場合はその旨を明記
- 該当する情報が見つからなかった場合は「該当なし」と明記
```

**注意:**
- 進捗・タスクの質問では、`docs/plan/` カテゴリファイル（進行中・未着手のみ）で通常は完結する。完了済みタスクの過去の経緯を問われた場合のみ `docs/plan/archive/` / `docs/tasks/archive/` を参照する
- 質問が広範な場合は、カテゴリ別に複数のサブエージェントを並列で起動してよい（最大3並列）
- 質問が具体的で対象ファイルが明確な場合は、サブエージェントを使わず直接 Read で確認してもよい

## 3. 回答の作成

調査結果をもとに、以下の形式で回答してください。

```markdown
## 回答

{質問に対する回答。簡潔かつ正確に。}

### 参照元

- `{ファイルパス}`: {どの情報を参照したか}
- `{ファイルパス}`: {どの情報を参照したか}
```

### 回答のガイドライン

- **簡潔に**: 聞かれたことに直接答える。不要な前置きや補足は省く
- **正確に**: ドキュメントに基づいて回答する。推測で補う場合は明記する
- **参照元を示す**: 回答の根拠となったファイルパスを必ず記載する
- **該当なし**: ドキュメントに記載がない場合は「現在のドキュメントには記載がありません」と回答する
- **コード参照**: 実装詳細の質問では、ファイルパスと行番号を含める
